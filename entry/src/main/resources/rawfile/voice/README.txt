第一组使用完整的动作与呼吸指导；后续组只需要简短提示音：ready / tighten / relax / finish / pause。breathe 作为安全提醒保留。

当前原型已内置英文 MP3 提示，以及准备阶段的 3、2、1 倒计时。训练时优先使用随包音频，播放失败再回退 HarmonyOS TTS；中文和英文均可用。

第 2 组及之后会绕过较长的 MP3 教学录音，使用单词级 HarmonyOS TTS（中英）播报收紧、放松、完成、暂停等短提示；倒计时数字仍保持简短播报。

这些原型音频由 Google Translate TTS 生成。上架前请确认语音服务的再分发许可，必要时替换为已获得授权的录音或自有 TTS 产物。
